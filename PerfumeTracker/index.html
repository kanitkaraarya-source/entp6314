🌸 Perfume Price Tracker

Tracks price drops and price hikes across retailers, and shows where each fragrance is cheapest right now.

Demo data. This build ships with a sample dataset (fictional prices, generated 14-day trend) so the tracking, sorting and "cheapest retailer" logic can be tried end-to-end. Wire PERFUMES in index.html up to a real price feed (retailer APIs or a scheduled scraper) to make it live — see the comment at the top of the script.
